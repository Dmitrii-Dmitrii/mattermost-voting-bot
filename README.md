# mattermost-voting-bot

## Описание
Данный проект представляет собой плагин для Mattermost, работающий с использованием Tarantool. Данный плагин предоставляет возможность работать с голосованиями в чате.

## Использование

Основной командой является `/vote`, которая имеет несколько параметров:
- `/vote create [question] [answers] [flags]`
- `/vote answer [voteId] [answers]`
- `/vote result [voteId]`
- `/vote close [voteId]`
- `/vote delete [voteId]`

---

### `/vote create [question] [answers] [flags]`
Данная команда создает голосование и возвращает в чат его id (`voteId`) и варианты ответов. 

Секции:
- `[question]` - вопрос в голосовании, должен быть указан в кавычках;
- `[answer]` - ответы в голосовании, должны быть указан в кавычках, может быть один или несколько;
- `[flags]` - опциональные флаги, которые настраивают голосование: 
    - `--multiple-answers` - указывает, можно ли дать несколько ответов;
    - `--anonymous` - указывает, является ли голосование анонимным;
    - `--expires-at` - устанавливает время окончания голосования, после этого флага в кавычках нужно указать время в формате `"hhhh-mm-ddThh:mm:ssZ"`.

Пример команды: `/vote create "Do you like Go?" "Yes" "No" "Never used" --multiple-answers`.

---

### `/vote answer [voteId] [answers]`
Данная команда позволяет дать ответ в голосовании.

Секции:
- `[voteId]` - id голосования;
- `[answer]` - ответы в голосовании, должны быть указан в кавычках, может быть один или несколько в зависимости от настроек голосования (флаг `--multiple-answers`).

Пример команды: `/vote answer 3715191946 "Yes"`.

---

### `/vote result [voteId]`
Данная команда показывает результаты голосования, если голосование публичное, будут выведены ответы пользователей и их количество, если приватное, только ответы и их количество.

Секции:
- `[voteId]` - id голосования.

Пример команды: `/vote result 3715191946`.

---

### `/vote close [voteId]`
Данная команда завершает голосование, причем это может сделать только его создатель.

Секции:
- `[voteId]` - id голосования.

Пример команды: `/vote close 3715191946`.

> **Примечание:** в команде `/vote create` можно указать флаг `--expires-at`, тогда при наступлении этого момента, голосование само завершится.

---

### `/vote delete [voteId]`
Данная команда удаляет голосование, причем это может сделать только его создатель.

Секции:
- `[voteId]` - id голосования.

Пример команды: `/vote delete 3715191946`.

---

## Инструкция по сборке

### Запуск плагина
Для запуска приложения необходимо склонировать данный репозиторий и перейти в его директорию:
```
git clone https://github.com/Dmitrii-Dmitrii/mattermost-voting-bot.git
cd mattermost-voting-bot
```
Далее нужно перейти в директорию `/docker`. Внутри нее находится `docker-compose.yml`, который отвечает за развертывание Mattermost и Tarantool. Его нужно запустить:
```
cd docker
docker-compose up -d
```
После запуска нужно перейти по [http://localhost:8065/](http://localhost:8065/), где будет находиться Mattermost. Далее перейти в `System Console` -> `Plugins` -> `Plugin Management` и загрузить туда архив с плагином `mattermost-voting-bot.tar.gz`. После активации плагина он будет доступен в чате. 

### Запуск тестов

Для тестов также используется `docker-compose.yml`, который находится в `./test/docker_test`, он используется для развертывания Tarantool. Однако в данном случае запускать `docker-compose.yml` не нужно, это встроено в тесты. Для их запуска нужно выполнить следующие команды:
- `storage_test`
```
cd test
go test -v
```

- `plugin_test`
```
cd plugin
go test -v
```
